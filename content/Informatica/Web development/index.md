# Web development

Dit zijn mijn aantekeningen bij de online cursus over web development. De cursus is in het Engels; de uitleg hier staat in het Nederlands, de codevoorbeelden blijven in HTML.

## Wat is HTML?

HTML (HyperText Markup Language) is de taal waarmee je de **inhoud en structuur** van een webpagina bepaalt. Met HTML voeg je bijvoorbeeld koppen, afbeeldingen, links en lijsten toe.

Alle onderwerpen staan bij elkaar op de [[Web development/HTML/|HTML-overzichtspagina]].
