# Voorbeeld met headers

Een eerste klein programma: een kop in een rij, op basis van een Bootstrap-voorbeeld uit de cursus.

```html
<div class="row">
  <div class="col-md-6 col-md-offset-3">
    <h1>testing 123</h1>
  </div>
</div>
```

Deze code voegt een `<h1>`-kop toe binnen een container die de tekst op de pagina centreert.

Meer over koppen: [[Headers in HTML]].
